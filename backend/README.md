# Ridezy Backend

Express 5 + TypeScript + MongoDB Atlas (Mongoose) + Socket.IO.

## Quick start

```bash
cp .env.example .env     # fill in MONGODB_URI, JWT_SECRET, OTP_SECRET
npm install
npm run dev              # http://localhost:5000
```

Without `EMAIL_*` set (development only), emails go to a throwaway Ethereal
inbox and a preview link is logged for each one.

Create the admin account (there is no public endpoint for this):

```bash
# set ADMIN_NAME, ADMIN_EMAIL, ADMIN_PASSWORD in .env, then:
npm run create-admin
# then remove ADMIN_PASSWORD from .env
```

## Auth API

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | – | Create PASSENGER/DRIVER account, email a 6-digit OTP |
| POST | `/api/auth/verify-email` | – | Verify email with the OTP |
| POST | `/api/auth/resend-otp` | – | New OTP (60s cooldown) |
| POST | `/api/auth/login` | – | Returns a JWT (verified users only) |
| GET | `/api/auth/me` | Bearer token | Current user |
| GET | `/api/health` | – | Liveness + database status |

Profile APIs: `/api/passengers/*` (PASSENGER), `/api/drivers/*` (DRIVER), `/api/admin/*` (ADMIN).
Ride APIs: `/api/rides/*` (estimate, book, current, cancel, accept/reject). Full reference at `/api/docs`.
Import `postman/Ridezy.postman_collection.json` into Postman to try every endpoint.

Ride chat & in-app calls (passenger ↔ assigned driver, while the ride is active) run over
Socket.IO + WebRTC. REST: `GET /api/rides/:rideId/messages` and `/communication`. The
socket event contract, error codes and WebRTC (STUN/TURN) setup are in
[`docs/realtime-events.md`](docs/realtime-events.md).

## Deploy (Render)

The repo-root `render.yaml` is a Render Blueprint for this backend (Node web
service, `rootDir: backend`, health check `/api/health`, WebSockets supported).

1. Push the repo to GitHub. In Render: **New → Blueprint** → select the repo.
2. Fill in the values Render asks for (`sync: false` in `render.yaml`): `MONGODB_URI`,
   `CORS_ORIGIN` / `APP_URL` (your Vercel URL), `BREVO_API_KEY` + `EMAIL_FROM`, `SUPABASE_*`,
   `RAZORPAY_*`. (Render's free plan blocks SMTP ports, so email is sent over HTTPS via Brevo.)
   `JWT_SECRET` and `OTP_SECRET` are generated by Render.
3. MongoDB Atlas → **Network Access**: allow Render to connect (`0.0.0.0/0`, or Render's
   static outbound IPs on paid plans).
4. Razorpay → Webhooks: `https://<service>.onrender.com/api/payments/razorpay/webhook`.
5. Vercel (frontend): `NEXT_PUBLIC_API_URL=https://<service>.onrender.com/api`, redeploy.

Not Vercel/serverless: Socket.IO (chat, live tracking, live notifications, calls) needs a
long-running server.
